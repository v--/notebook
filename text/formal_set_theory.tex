\section{Formal set theory}\label{sec:formal_set_theory}

We start with some basics of set theory from the perspective of \fullref{ch:mathematical_logic}. In particular, the results will be based on derivability via formal proofs. This will allow us to formulate very general definitions like the inclusion order in \cref{def:inclusion_order} and the lattice of sets in \cref{def:lattice_of_sets} that would otherwise require more awkward model-theoretic counterparts.

In later sections, we will work in a less formal metalanguage.

\paragraph{Axiomatic set theory}

\begin{definition}\label{def:axiomatic_set_theory}\mimprovised
  \term[en=axiomatic set theory (\cite[xii]{Hinman2005Logic})]{Axiomatic set theory} may refer to any \hyperref[def:logical_theory]{logical theory} based on a single binary \hyperref[con:predicate_logic/predicate]{predicate} \( \synin \), called \term[en=membership relation (\cite[5]{Jech2006SetTheory})]{set membership}\fnote{Other operations and predicates can be added as \hyperref[con:syntactic_abbreviation]{abbreviations} or \hyperref[def:fol_definitional_extension]{definitional extensions} --- see \cref{def:set_theory_definition} --- but we must be careful not to add additional structure.}. The adjective \enquote{axiomatic} is meant to highlight that the theory is stated in a fixed \hyperref[con:logical_system]{logical system}, as opposed to the informal theory like the one Cantor originally described in \cite{Кантор1985Многообразия}.

  The theories we will consider will be first-order adaptations, in the sense of \cref{def:fol_adaptation_of_monadic_sol_theory}, of \hyperref[def:second_order_logic]{monadic second-order} \hyperref[def:hol_theory]{theories}. This particular choice of formalisms is due to established practice --- see \cref{rem:first_order_zfc}.

  \begin{thmenum}
    \thmitem{def:axiomatic_set_theory/extensionality}\mcite[16]{Kunen2013SetTheory} Different set theories differ by their axioms --- these are existential axioms that postulate that a particular construction we can informally describe is actually well-defined.

    An exception is the \term[ru=аксиома объёмности (\cite[180]{Герасимов2014Вычислимость})]{axiom of extensionality}, which expresses the essence of a set --- namely, that a set is completely determined by its members\fnote{Technically, we must take the \hyperref[def:fol_quantifier_closure]{universal closure} of \eqref{eq:def:axiomatic_set_theory/extensionality}.}:
    \begin{equation}\label{eq:def:axiomatic_set_theory/extensionality}
      \qforall \synz (\synz \synin \synx \syniff \synz \synin \syny) \synimplies \synx \syneq \syny.
    \end{equation}

    The converse follows by a simple application of \ref{inf:def:fol_natural_deduction/equality/elim}.

    \thmitem{def:axiomatic_set_theory/atoms}\mimprovised In \cite{Zermelo2010Collection:GrundlagenDerMengenlehre}, where Zermelo introduces his axiomatization of set theory, he assumes the existence of a \enquote{Bereich} (\enquote{domain}) consisting of \enquote{Dinge} (\enquote{things}). Some of these things are assumed to be \enquote{Mengen} (\enquote{sets}).

    Later on, as set theory develops, the perspective shifts and objects that are not sets became secondary. They become known as \term[en=atom (\cite[27]{Schechter1997AnalysisHandbook})]{atoms} or \term[en=urelement (\cite[238]{Shoenfield1967MathematicalLogic})]{urelements}\fnote{The word \enquote{urelement} uses the German prefix \enquote{ur}, meaning \enquote{primordial}. According to \cite{MacTutor:EarliestUsesOfMathWordsU}, the term is borrowed from Zermelo's \cite{Zermelo2010Collection:GrenzzahlenUndMengenbereiche}.}

    Atoms can be formalized using \hyperref[def:many_sorted_fol]{many-sorted first-order logic} with a dedicated sort \( \syn\sigma \) (\enquote{\textel{σύνολο}}) for sets and a separate relation \( \synin_S: S \synimplies \syn\sigma \synimplies \syn\omicron \) for every sort \( S \).

    Since atoms are not essential for set theory, and since many-sorted logic introduces considerable overhead, it is customary to study unisorted set theory, where the only individuals are sets. We call such sets \term[en=pure (sets) (\cite[238]{Shoenfield1967MathematicalLogic})]{pure}.
  \end{thmenum}
\end{definition}
\begin{comments}
  \item See \cref{def:set_theory_definition} for a convenient syntax for describing sets.
  \item We discuss set existence in \cref{con:set_theory_class}.
\end{comments}

\begin{remark}\label{rem:epsilon_and_set_membership}
  In \cite{MacTutor:EarliestUsesOfLogicSymbols}, the symbol \enquote{\( \in \)} for \hyperref[def:axiomatic_set_theory]{set membership} is attributed to Peano's \cite{Peano1889ArithmeticesPrincipia}. Peano himself claims to have derived the symbol from the Latin word \enquote{\textla{est}} (\enquote{it is}).

  Peano himself used the stylized epsilon symbol \enquote{\( \in \)}, however some later books like \cite{Hausdorff1935Mengenlehre} use \enquote{\( \varepsilon \)}. The usual epsilon occurs as late as half a century later, with \cite{Kelley1975GeneralTopology} and \cite{Halmos1976MeasureTheory}.

  The use of epsilon explains the name \fullref{thm:epsilon_induction}.
\end{remark}

\begin{remark}\label{rem:set_theory_acronyms}
  \hyperref[def:axiomatic_set_theory]{Axiomatic set theories} have several established acronyms:
  \begin{thmenum}
    \thmitem{rem:set_theory_acronyms/zfc} The ubiquitous acronym \logic{ZFC} is used for \hyperref[def:zfc]{Zermelo-Fraenkel set theory} with the axiom of choice. We list some variations.
    \begin{itemize}
      \thmitem{rem:set_theory_acronyms/zf} \logic{ZF} denotes \logic{ZFC} without the axiom of choice. The two theories are often introduced simultaneously, for example in
      \cite[510]{Hinman2005Logic},
      \cite[3]{Jech2006SetTheory},
      \cite[17]{Kunen2013SetTheory},
      \cite[253]{Shoenfield1967MathematicalLogic} and
      \cite[161]{КолмогоровДрагалин2006ЛогикаДополнительныеГлавы}.

      \thmitem{rem:set_theory_acronyms/zfcu} As discussed in \cref{def:grothendieck_universe}, for the purposes of \hyperref[ch:category_theory]{category theory}, we assume the existence of a \hyperref[def:grothendieck_universe]{Grothendieck universe} in addition to the axioms of \logic{ZFC}. We denote this theory by \hyperref[def:zfcu]{\logic{ZFC+U}}, although this is not an established notation.

      \Cref{thm:grothendieck_universe_iff_regular_strong_limit} implies that the Grothendieck universes are precisely the \hyperref[rem:strongly_inaccessible_cardinal]{strongly inaccessible cardinals}, which leads to the acronym \logic{ZFC+I} used in \cite[167]{Jech2006SetTheory} and \cite[16]{Shulman2008SetTheoryForCategoryTheory}.

      \thmitem{rem:set_theory_acronyms/zfcs} A variant specifically constructed for \hyperref[ch:category_theory]{category theory} is \logic{ZFC/S} (\enquote{\logic{ZFC} with smallness}), which we briefly discuss in \cref{rem:small_category/reflection}.
    \end{itemize}

    \thmitem{rem:set_theory_acronyms/nbg} \hyperref[def:nbg]{von Neumann-Bernays-G\"odel set theory} can be by different acronyms. For example, \logic{BG} is used in \cite[70]{Jech2006SetTheory}, \logic{NBG} is used in \cite[232]{Mendelson2015Logic}, while \logic{NGB}is used in \cite[151]{Kunen2013SetTheory}.

    In a footnote, \textcite[231]{Mendelson2015Logic} writes the following:
    \begin{displayquote}
      I coined the name NBG in honor of von Neumann, Bernays, and G\"odel. Paul Halmos, who favored the Zermelo-Fraenkel system, suggested that \enquote{NBG} stood for \enquote{No Bloody Good.}
    \end{displayquote}

    \thmitem{rem:set_theory_acronyms/mk} Another set theory is \logic{MK}, named after Morse and Kelley, and attributed by \textcite[\S 4.6.1]{Mendelson2015Logic} to the appendix of Kelley's \cite[201]{Kelley1975GeneralTopology}.

    We will not examine \logic{MK} in this monograph.
  \end{thmenum}
\end{remark}

\begin{definition}\label{def:set_theory_model}\mimprovised
  Let \( T \) be a (first-order) \hyperref[def:axiomatic_set_theory]{axiomatic set theory}, an \hyperref[def:fol_adaptation_of_monadic_sol_theory]{adaptation} of the second-order theory \( T_2 \).

  A \hyperref[def:fol_semantics/model]{first-order model} \( \mscrM = (M, I) \) of \( T \) is characterized mainly by the universe \( M \) and the membership interpretation \( I(\synin) \). Unless we are dealing with additional structure like \hyperref[def:axiomatic_set_theory/atoms]{urelements} or \hyperref[def:nbg]{classes}, both first-order and second-order models can be regarded as pairs \( (M, I(\synin)) \).

  \begin{thmenum}
    \thmitem{def:set_theory_model/standard} \Cref{def:fol_adaptation_of_monadic_sol_theory} suggests calling \( \mscrM \) \enquote{standard} if it is a model of \( T_2 \).

    This is well-suited for some theories like \hyperref[def:peano_arithmetic]{Peano arithmetic}, whose second-order variants are \hyperref[def:hol_theory/categorical]{categorical} --- all standard models are isomorphic, so for many purposes it is immaterial which one we work with.

    Unfortunately, as a set theory, \( T_2 \) is likely not \hyperref[def:hol_theory/categorical]{categorical}. For example, \fullref{thm:zermelos_quasi_categoricity_theorem} characterizes the models of \hyperref[def:zfc]{\( \logic{ZFC}_2 \)} as the \hyperref[def:grothendieck_universe]{Grothendieck universes}, of which there is a hierarchy. Some categorical second-order set theories are explored in \cite{HamkinsSolberg2020SetTheoreticReflection}.

    We refrain from speaking about \enquote{standard models} of set theory.

    \thmitem{def:set_theory_model/transitive}\mcite[def. I.15.1]{Kunen2013SetTheory} It is most natural to study models \( (M, {\in}) \), where \( M \) is a set and \( {\in} \) is the metatheoretic membership relation restricted to \( M \)\fnote{Kunen calls such models \enquote{\( \in \)-models}.}.

    This is by itself a weak condition because of the following subtle problem: \( B \in A \in M \) does not by itself imply that \( B \in M \). It is thus possible for metatheoretic members of \( A \) to not be considered members \emph{inside} \( (M, {\in}) \).

    If this cannot happen, we call the model \term[ru=транзитивная (модель) (\cite[\S 4.7.2]{КусраевКутателадзе2005БулевозначныйАнализ})]{transitive}. The universe of a transitive model is a transitive set in the sense of \cref{def:transitive_set}.
  \end{thmenum}
\end{definition}

\begin{definition}\label{def:set}\mimprovised
  We will refer to any element of any model of any \hyperref[def:axiomatic_set_theory]{axiomatic set theory} as a \term{set}.
\end{definition}
\begin{comments}
  \item Unless explicitly mentioned otherwise, sets are assumed to belong to a fixed \hyperref[def:set_theory_model/transitive]{transitive} model of \hyperref[def:zfcu]{\logic{ZFC+U}}.

  \item Because of the \hyperref[def:axiomatic_set_theory/extensionality]{axiom of extensionality}, a set is determined by its members, leading to the ubiquitous set-builder notation we discuss in \cref{def:set_theory_definition}. To show that a hypothetical set is well-defined, we only need to prove that a set with these exact members exists. See \cref{con:set_theory_class}.
\end{comments}

\paragraph{Naive set theory}

\begin{remark}\label{rem:naive_set_theory}
  The phrase \enquote{naive set theory} can have two meanings:
  \begin{thmenum}
    \thmitem{rem:naive_set_theory/informal} \enquote{Naive} may refer to the informal (i.e. non-\hyperref[def:axiomatic_set_theory]{axiomatic}) set theory initially studied by Cantor. In this sense, the phrase is used, for example, in
    \cite[11]{Enderton1977SetTheory} and
    \cite[\S I.1]{Aluffi2009Algebra}.

    Paul Halmos describes his book \cite{Halmos1960NaiveSetTheory} as \enquote{axiomatic set theory from the naive point of view} because he explains \hyperref[def:zfc]{\logic{ZFC}} without focusing on formalities.

    \thmitem{rem:naive_set_theory/formal} \enquote{Naive set theory} may refer to the specific axiomatic set theory with unrestricted comprehension --- the one we state in \cref{def:naive_set_theory}. In this sense, the phrase is used in
    \cite[\S I.1]{КолмогоровДрагалин2006ЛогикаДополнительныеГлавы} and
    \cite[\S 3.4]{Герасимов2014Вычислимость}.

    \Textcite[\S 5.3.1]{Mimram2020ProgramEqualsProof} uses the phrase \enquote{naive set theory} for the axiomatic theory with unrestricted comprehension but without extensionality.

    \Textcite[xii]{Andrews2002Logic} uses a very appropriate term, \enquote{naive axiomatic set theory}, which we utilize.
  \end{thmenum}
\end{remark}

\begin{definition}\label{def:naive_set_theory}\mimprovised
  A particularly simple \hyperref[def:axiomatic_set_theory]{axiomatic set theory} is \term[ru=наивная теория множеств, en=naive axiomatic set theory (\Textcite[xii]{Andrews2002Logic})]{naive axiomatic set theory}, with only one existential axiom.

  \begin{thmenum}
    \thmitem{def:naive_set_theory/comprehension} The \term[en=unrestricted comprehension (\cite[240]{Mimram2020ProgramEqualsProof})]{axiom schema of unrestricted comprehension} states that any \hyperref[def:fol_formula]{first-order formula} \( \varphi \) determines a set:
    \begin{equation}\label{eq:def:naive_set_theory/comprehension}
      \qexists \syna \qforall \synx (\synx \synin \syna \syniff \syn\varphi).
    \end{equation}

    Note that \eqref{eq:def:naive_set_theory/comprehension} is a formula schema in the sense of \cref{def:fol_formula_schema}. An \hyperref[con:schemas_and_instances]{instance} of \( \syn\varphi \) may have free variables other than \( \synx \), so we must take the \hyperref[def:fol_quantifier_closure]{universal closure} of each concrete instance.

    The schema is a adaptation, in the sense of \cref{def:fol_adaptation_of_monadic_sol_theory}, of the following second-order axiom:
    \begin{equation}\label{eq:def:naive_set_theory/comprehension/sol}
      \qforall {\synp^{\syn\iota \synimplies \syn\omicron}} \qexists {\syna^{\syn\iota}} \qforall {\synx^{\syn\iota}} (\synx \synin \syna \syniff \synp \synx).
    \end{equation}
  \end{thmenum}
\end{definition}
\begin{comments}
  \item See \cref{rem:naive_set_theory} for how different authors describe this theory.
\end{comments}

\begin{definition}\label{def:set_theory_definition}
  An \hyperref[def:axiomatic_set_theory]{axiomatic set theory} \( T \) generally features no \hyperref[def:fol_signature/function]{function symbols}, making variables the only \hyperref[def:fol_term]{logical terms}.

  \hyperref[def:naive_set_theory/comprehension]{Unrestricted comprehension} and its less powerful variants like \hyperref[def:zfc/specification]{specification} allow introducing function symbols as \hyperref[def:fol_definition/function]{first-order definitions}, thus not interfering with the logical properties of the theory. Many such symbols are aggregated in \cref{thm:zfc_existence_theorems}.

  Fix a \hyperref[def:fol_formula]{formula} \( \varphi \) whose free variables are \( \synx, p_1, \ldots, p_n \). The corresponding instance of unrestricted comprehension is
  \begin{equation*}
    \qforall {p_1} \ldots \qforall {p_n} \qexists a \qforall x (x \synin \syna \syniff \varphi).
  \end{equation*}

  With uniqueness provided by extensionality, the above acts as a proof of correctness for a definition of an \( n \)-ary \hyperref[def:fol_signature/function]{function symbol} \( A \):
  \begin{equation*}
    \qforall {p_1} \ldots \qforall {p_n} \qforall a \parens[\big]{ (A(p_1, \ldots, p_n) \syneq \syna) \syniff \qforall x (x \synin \syna \syniff \varphi)) }.
  \end{equation*}

  We can now use \( A \) to construct terms in the corresponding \hyperref[def:fol_definitional_extension]{definitional extension} \( T^+ \). Any formula and any proof in \( T^+ \) can be encoded more verbosely in \( T \).

  We call \( A \) a \term{definition by specification} and we call the variables \( p_1, \ldots, p_n \) \term{parameters}. For convenience, we will use the following metasyntax, called \term[en=set-builder notation (\cite[10]{CitkinMuravitsky2022ConsequenceRelations})]{set-builder notation}.:
  \begin{equation*}
    A(p_1, \ldots, p_n) \coloneqq \set{ x \given \varphi }.
  \end{equation*}

  Of course, if \( n = 0 \), we avoid the parameter list altogether and write
  \begin{equation*}
    A \coloneqq \set{ x \given \varphi }.
  \end{equation*}

  \begin{thmenum}
    \thmitem{def:set_theory_definition/function} Some variations of this notation are common. For example, if \( g \) is a unary function symbol, we can define \( A \) by
    \begin{equation*}
      \qforall {p_1} \ldots \qforall {p_n} \qforall a \parens[\big]{ (A(p_1, \ldots, p_n) \syneq a) \syniff \qforall x (g(x) \synin \syna \syniff \varphi)) }.
    \end{equation*}
    and denote it as
    \begin{equation*}
      A(p_1, \ldots, p_n) \coloneqq \set{ g(x) \given \varphi }.
    \end{equation*}

    \thmitem{def:set_theory_definition/restricted} With the axiom schema specification, which provides restricted comprehension, we must formally add an additional parameter \( u \) and substitute \( \varphi \) with \( x \in u \synwedge \varphi  \), but informally we can simply write
    \begin{equation*}
      A(p_1, \ldots, p_n, u) \coloneqq \set{ x \synin u \given \varphi }.
    \end{equation*}

    If \( n = 0 \), by fixing a closed term \( \tau \) to substitute for \( u \), we can avoid the parameter list altogether and write
    \begin{equation*}
      A \coloneqq \set{ x \synin \tau \given \varphi }
    \end{equation*}

    \thmitem{def:set_theory_definition/roster} Finally, if \( \varphi = (x \syneq \tau_1) \synvee \cdots \synvee (x \syneq \tau_n) \) for closed terms \( \tau_1, \ldots, \tau_n \), we simply enumerate the terms:
    \begin{equation*}
      A \coloneqq \set{ \tau_1, \ldots, \tau_n }.
    \end{equation*}

    This is sometimes called \term[en=roster notation (\cite[10]{CitkinMuravitsky2022ConsequenceRelations})]{roster notation}.

    \thmitem{def:set_theory_definition/predicate} If \( p_1, \ldots, p_n \) are free variables in \( \varphi \), we can shorten the \hyperref[def:fol_definition/predicate]{first-order predicate definition}
    \begin{equation*}
      \qforall {p_1} \cdots \qforall {p_n} (P(p_1, \ldots, p_n) \syniff \varphi)
    \end{equation*}
    to
    \begin{equation*}
      P(p_1, \ldots, p_n) \coloneqq \varphi.
    \end{equation*}
  \end{thmenum}
\end{definition}
\begin{comments}
  \item We formalize common patterns ubiquitous in the practical use of sets. The concrete phrase \enquote{set builder notation} can be found in \cite[10]{CitkinMuravitsky2022ConsequenceRelations} and \cite[122]{Rosen2019DiscreteMathematics}.
\end{comments}

\begin{theorem}[Russell's paradox]\label{thm:russels_paradox}
  \hyperref[def:naive_set_theory]{Naive set theory} is \hyperref[def:fol_theory/consistent]{inconsistent}. More precisely, consider the set
  \begin{equation*}
    \synR \coloneqq \set{ \synx \given \synneg (\synx \synin \synx) }.
  \end{equation*}

  Using \hyperref[def:fol_natural_deduction_system]{classical natural deduction}, we can derive both \( \synR \synin \synR \) and \( \synneg (\synR \synin \synR) \).
\end{theorem}
\begin{comments}
  \item Here \( R \) is formally defined as per \cref{def:set_theory_definition}. We do not associate it as a set in some model of set theory because, by \fullref{thm:fol_completeness}, an inconsistent theory is not satisfiable.

  \item This paradox arises from self-reference and is one of several; see \cref{ex:self_reference/russells_paradox}.
\end{comments}
\begin{proof}
  The first-order definition of \( \synR \) is given by
  \begin{equation*}
    \qforall \synx (\synx \synin \synR \syniff \synneg (\synx \synin \synx)).
  \end{equation*}

  We can derive
  \begin{equation*}
    \begin{prooftree}
      \hypo{ [\qforall \synx (\synx \synin \synR \syniff \synneg (\synx \synin \synx))]^u }
      \infer1[\ref{inf:def:fol_natural_deduction/forall/elim}]{ \synR \synin \synR \syniff \synneg (\synR \synin \synR) }

      \hypo{ [\synR \synin \synR]^v }
      \infer2[\ref{inf:def:propositional_natural_deduction/iff/elim_right}]{ \synneg (\synR \synin \synR) }

      \hypo{ [\synR \synin \synR]^v }
      \infer2[\ref{inf:def:propositional_natural_deduction/neg/elim}]{ \synbot }

      \infer[left label={\( v \)}]1[\ref{inf:def:propositional_natural_deduction/neg/intro}]{ \synneg (\synR \synin \synR) }
    \end{prooftree}
  \end{equation*}

  Denote the above derivation tree by \( P \). It allows us to also derive
  \begin{equation*}
    \begin{prooftree}
      \hypo{ [\qforall \synx (\synx \synin \synR \syniff \synneg (\synx \synin \synx))]^u }
      \infer1[\ref{inf:def:fol_natural_deduction/forall/elim}]{ \synR \synin \synR \syniff \synneg (\synR \synin \synR) }

      \hypo{ [\qforall \synx (\synx \synin \synR \syniff \synneg (\synx \synin \synx))]^u }
      \ellipsis {\( P \)} { \synneg (\synR \synin \synR) }

      \infer2[\ref{inf:def:propositional_natural_deduction/iff/elim_left}]{ \synR \synin \synR }
    \end{prooftree}
  \end{equation*}
\end{proof}

\begin{concept}\label{con:set_theory_class}\mcite[notation I.4.4]{Kunen2013SetTheory}
  \Fullref{thm:russels_paradox} implies that, in \hyperref[def:naive_set_theory]{naive (axiomatic) set theory}, \hyperref[def:naive_set_theory/comprehension]{unrestricted comprehension} allows us to easily define paradoxical sets. More generally, in other \hyperref[def:axiomatic_set_theory]{axiomatic set theories}, \hyperref[def:set_theory_definition]{set-builder notation} allows us to describe sets which may not be well-defined in the underlying theory.

  We refer to any possibly ill-defined set constructed via unrestricted comprehension as a \term[ru=класс (\cite[24]{ШеньВерещагин2020НачалаТеорииМножеств})]{class}. If a class is not a well-defined set, we call it a \term{proper class}. Even if they are formally unsound, classes are sometimes convenient.

  \begin{itemize}
    \item In naive set theory, all classes are sets.

    \item In \hyperref[def:zfc]{\logic{ZFC}}, most classes of interested are sets (as shown in \cref{thm:zfc_existence_theorems}, but some easily defined ones like the \hyperref[def:universal_set]{universal set} are not (despite the name). Classes can be regarded as subsets of a \hyperref[def:set_theory_model/transitive]{transitive model} of \logic{ZFC}, while sets are members of the model.

    \item Finally, some axiomatic set theories like \hyperref[def:nbg]{\logic{NBG}} has a formal notion of a proper class.
  \end{itemize}
\end{concept}

\begin{definition}\label{def:universal_set}\mimprovised
  As justified by \cref{def:set_theory_definition}, in \hyperref[def:naive_set_theory]{naive set theory}, we can easily define the \term[en=universal set (\cite[xvi]{Mendelson2015Logic})]{universal set}
  \begin{equation*}
    \synV \coloneqq \set{ \synx \given \syntop }.
  \end{equation*}

  Similarly to how Russell's set from \fullref{thm:russels_paradox} demonstrates the inconsistency of naive set theory, we will show in \fullref{thm:cantors_paradox} how the universal set also leads to a similar result.

  Thus, the universal set exists only as a formal concept (a \enquote{\hyperref[con:set_theory_class]{class}}) without a well-defined interpretation.
\end{definition}

\paragraph{Power sets}

\begin{definition}\label{def:subset}\mcite[10]{Мальцев1970АлгебраическиеСистемы}
  If every member of the \hyperref[def:set]{set} \( A \) is a member of \( B \), we say that \( A \) is a \term[bg=подмножество (\cite[144]{Тагамлицки1978ИнтегралноСмятане}), ru=подмножество, en=subset (\cite[def. 2.1.3]{Rosen2019DiscreteMathematics})]{subset} of \( B \) and write \( A \subseteq B \), and similarly we say that \( B \) is a \term[bg=подмножество (\cite[144]{Тагамлицки1978ИнтегралноСмятане}), ru=надмножество, en=superset (\cite[def. 2.1.3]{Rosen2019DiscreteMathematics})]{superset} of \( A \) and write \( B \supseteq A \).

  If \( A \subseteq B \) and \( A \neq B \), we say that the subset \( A \) is \term[ru=собственное (подмножество) (\cite[34]{БелоусовТкачёв2004ДискретнаяМатематика}), en=proper (subset) (\cite[126]{Rosen2019DiscreteMathematics})]{proper} or \term[ru=строгое (подмножество) (\cite[34]{БелоусовТкачёв2004ДискретнаяМатематика}), en=strict (subset) (\cite[403]{Müller2022HandbookOfDynamicsAndProbability})]{strict} of \( B \) and write \( A \subsetneq B \).

  Formally, in accordance with \cref{def:set_theory_definition/predicate}, we can introduce an \hyperref[def:fol_signature/notation]{infix} binary \hyperref[def:fol_signature/predicate]{predicate symbol}:
  \begin{equation*}
    (\syna \synsubseteq \synb) \coloneqq \qforall \synx (\synx \synin \syna \synimplies \synx \synin \synb).
  \end{equation*}
\end{definition}
\begin{comments}
  \item The subsets of a fixed set come with the structure of a \hyperref[def:boolean_algebra/complete]{complete Boolean algebra} --- see \cref{def:power_set_algebra}.
\end{comments}

\begin{proposition}\label{thm:inclusion_order}
  The \hyperref[def:subset]{subset predicate} \( {\synsubseteq} \) satisfies the axioms of the \hyperref[def:partially_ordered_set/theory]{theory of partially ordered sets}.
\end{proposition}
\begin{proof}
  To avoid unnecessary details, we assume that the variable names are chosen as needed for \cref{def:partially_ordered_set/theory}.

  We will use the expanded formula \( \qforall x (x \synin \syna \synimplies x \synin b) \) rather than \( \syna \synsubseteq b \).

  \SubProofOf[def:binary_relation/reflexive]{reflexivity}
  \begin{equation*}
    \begin{prooftree}
      \infer0[\ref{inf:thm:propositional_admissible_rules/self_conditional}]{ x \synin \syna \synimplies x \synin a }
      \infer1[\ref{inf:def:fol_natural_deduction/forall/intro}]{ \qforall x (x \synin \syna \synimplies x \synin a) }
    \end{prooftree}
  \end{equation*}

  \SubProofOf[def:binary_relation/antisymmetric]{antisymmetry}
  \begin{equation*}
    \begin{prooftree}
      \hypo{ [\qforall x (x \synin \syna \synimplies x \synin b)]^u }
      \infer1[\ref{inf:def:fol_natural_deduction/forall/elim}]{ x \synin \syna \synimplies x \synin b }

      \hypo{ [x \synin a]^t }
      \infer2[\ref{inf:def:propositional_natural_deduction/imp/elim}]{ x \synin b }

      \hypo{ \substack{ [\qforall x (x \synin \syna \synimplies x \synin b)]^v \\ [x \synin b]^s } }
      \ellipsis {} { x \synin a }

      \infer[left label={\( t, s \)}]2[\ref{inf:def:propositional_natural_deduction/iff/intro}]{ x \synin \syna \syniff x \synin b }
      \infer1[\ref{inf:def:fol_natural_deduction/forall/intro}]{ \qforall x (x \synin \syna \syniff x \synin b) }

      \hypo{ [\eqref{eq:def:axiomatic_set_theory/extensionality}]^w }
      \infer1[\ref{inf:def:fol_natural_deduction/forall/elim}]{ anon }
      \infer2[\ref{inf:def:propositional_natural_deduction/imp/elim}]{ \syna \syneq b }
    \end{prooftree}
  \end{equation*}

  \SubProofOf[def:binary_relation/transitive]{transitivity}
  \begin{equation*}
    \begin{prooftree}
      \hypo{ [\qforall x (x \synin \syna \synimplies x \synin b)]^u }
      \infer1[\ref{inf:def:fol_natural_deduction/forall/elim}]{ x \synin \syna \synimplies x \synin b }

      \hypo{ [x \synin a]^t }
      \infer2[\ref{inf:def:propositional_natural_deduction/imp/elim}]{ x \synin b }

      \hypo{ [\qforall x (x \synin b \synimplies x \synin c)]^v }
      \infer1[\ref{inf:def:fol_natural_deduction/forall/elim}]{ x \synin b \synimplies x \synin c }

      \infer2[\ref{inf:def:propositional_natural_deduction/imp/elim}]{ x \synin c }
      \infer[left label=\( t \)]1[\ref{inf:def:propositional_natural_deduction/imp/intro}]{ x \synin \syna \synimplies x \synin c }
      \infer1[\ref{inf:def:fol_natural_deduction/forall/intro}]{ \qforall x (x \synin \syna \synimplies x \synin c) }
    \end{prooftree}
  \end{equation*}
\end{proof}

\begin{definition}\label{def:inclusion_order}\mimprovised
  When regarded as a \hyperref[def:binary_relation]{binary relation} in some \hyperref[def:set_theory_model]{model} of \hyperref[def:axiomatic_set_theory]{axiomatic set theory}, we refer to the \hyperref[def:subset]{subset} predicate as the \term[ru=отношение включения (\cite[44]{Гуров2013ТеорияРешёток}), en=inclusion order (\cite[4]{DaveyPriestley2002LatticeTheory})]{inclusion order}. It follows from \cref{thm:inclusion_order} that it is a \hyperref[def:partially_ordered_set]{partial order} on the model itself, as well as on any collection of sets.
\end{definition}
\begin{comments}
  \item As shown in \cref{thm:lattice_of_sets}, this is a lattice order whose joins and meets and unions and intersections.
\end{comments}

\begin{definition}\label{def:power_set}\mcite[19]{Enderton1977SetTheory}
  For every set \( A \), we define the \term[ru=булеан (\cite[34]{БелоусовТкачёв2004ДискретнаяМатематика})]{power set} \( \pow(A) \) whose members are the \hyperref[def:subset]{subsets} of \( A \).

  Formally, in accordance with \cref{def:set_theory_definition}, we can use set-builder notation to introduce a unary \hyperref[def:fol_signature/function]{function symbol} \( {\syn\pow} \):
  \begin{equation*}
    \syn\pow(\syna) \coloneqq \set{ \synx \given \synx \synsubseteq \syna }.
  \end{equation*}

  We have used the subset predicate symbol \( {\synsubseteq} \) from \cref{def:subset}.
\end{definition}
\begin{comments}
  \item In \hyperref[def:zfc]{\logic{ZFC}}, the correctness of this definition relies on the \hyperref[def:zfc/power_set]{power set axiom} --- see \cref{thm:zfc_existence_theorems/power_set}.
\end{comments}

\paragraph{Sets of sets}

\begin{remark}\label{rem:sets_of_sets}
  In a \hyperref[def:axiomatic_set_theory/atoms]{pure set theory}, the members of sets are always sets.

  When speaking about numbers, functions, symbols or abstract structures, we regard their encoding as sets is a technicality. Thus, practically, speaking about sets of numbers or functions is not fundamentally different from speaking about informal collections of numbers or functions.

  On the other hand, we often have to deal with sets whose members we also regard as sets. To avoid repetition, it is convenient to call them \enquote{collections} or \enquote{families} of sets (\enquote{\textru{совокупность}} and \enquote{\textru{семейство}} in Russian). Both terms are introduced as a synonym for \enquote{set} in
  \cite[12]{Jech2006SetTheory},
  \cite[1]{Kelley1975GeneralTopology},
  \cite[1]{Willard2004GeneralTopology},
  \cite[27]{Rudin1976AnalysisPrinciples},
  \cite[2]{Folland1999RealAnalysis} and
  \cite[5]{Зорич2019АнализЧасть1}.

  We will avoid using the phrase \enquote{family of sets} because the word \enquote{family} can also refer to indexed family as defined in \cref{def:indexed_family}. This usage is introduced, for example,
  \cite[44]{Halmos1960NaiveSetTheory},
  \cite[81]{Bourbaki2004TheoryOfSets} and
  \cite[3]{Harzheim2005OrderedSets}.
\end{remark}

\begin{definition}\label{def:empty_set}\mcite[8]{Jech2006SetTheory}
  The dual of the paradoxical \hyperref[def:universal_set]{universal set} is the \term[ru=пустое множество (\cite[6]{ШеньВерещагин2020НачалаТеорииМножеств})]{empty set} \( \varnothing \) with no members.

  Formally, in accordance with \cref{def:set_theory_definition}, we can use set-builder notation to introduce a nullary \hyperref[def:fol_signature/function]{function symbol}:
  \begin{equation*}
    \syn\varnothing \coloneqq \set{ \synx \given \synbot }.
  \end{equation*}
\end{definition}
\begin{comments}
  \item In \hyperref[def:zfc]{\logic{ZFC}}, the correctness of this definition relies on the \hyperref[rem:zfc_formulations/empty_set]{axiom of the empty set} or an equivalent --- see \cref{thm:zfc_existence_theorems/empty_set}.

  \item This is an \hyperref[def:universal_objects/initial]{initial object} in the \hyperref[def:category_of_small_sets]{category of small sets} --- see \cref{thm:universal_sets}.
\end{comments}

\begin{definition}\label{def:subsingleton_set}\mcite[112]{UnivalentFoundationsProgram2013HoTT}
  If all elements of a set are equal, we call it a \term{subsingleton set}.
\end{definition}
\begin{comments}
  \item The term \enquote{subsingleton} is suggested as a term for \hyperref[def:mere_proposition]{mere proposition} in \cite[112]{UnivalentFoundationsProgram2013HoTT}. We adapt its usage for axiomatic set theory.

  On the other hand, \enquote{singleton} is a more popular term, given as a definition of axiomatic set theory in
  \cite[10]{Halmos1960NaiveSetTheory},
  \cite[7]{Jech2006SetTheory},
  \cite[3]{Kelley1975GeneralTopology},
  \cite[131]{КановейЛюбецкий2010СовременнаяТеорияМножеств} and
  \cite[129]{КолмогоровДрагалин2006ЛогикаВведение}.

  \item An empty set has zero elements, a singleton has one unique element, while a subsingleton may be either the empty set or a singleton. We give this more abstract definition which avoids direct references to numbers.
\end{comments}

\begin{definition}\label{def:singleton_set}\mcite[10]{Halmos1960NaiveSetTheory}
  We call a \hyperref[def:empty_set]{nonempty} \hyperref[def:singleton_set]{subsingleton set} a \term[ru=синглет (\cite[131]{КановейЛюбецкий2010СовременнаяТеорияМножеств}); синглетон (\cite[129]{КолмогоровДрагалин2006ЛогикаВведение})]{singleton}.

  Via \hyperref[def:set_theory_definition/roster]{roster notation}, we can denote the singleton containing \( A \) by \( \set{ A } \).
\end{definition}
\begin{comments}
  \item Since a singleton set is a special case of an \hyperref[def:unordered_pair]{unordered pair}, in \hyperref[def:zfc]{\logic{ZFC}}, the correctness of this definition relies on the \hyperref[def:zfc/pairing]{axiom of pairing} --- see \cref{thm:zfc_existence_theorems/singleton}.

  \item The singleton set \( \set{ A } \), where \( A \) is a \hyperref[def:small_set]{small set}, is a \hyperref[def:universal_objects/terminal]{terminal object} in the \hyperref[def:category_of_small_sets]{category of small sets} --- see \cref{thm:universal_sets}.

  \item It is sometimes convenient, especially in connection with \hyperref[ch:geometry]{geometry} or \hyperref[def:function]{set-valued maps} (e.g. when dealing with \hyperref[def:net_limit_point]{limits of nets} or \hyperref[def:subdifferentials]{subdifferentials}), to not distinguish between singleton sets and their corresponding element.
\end{comments}

\begin{definition}\label{def:unordered_pair}\mcite[9]{Halmos1960NaiveSetTheory}
  Given sets \( A \) and \( B \), via \hyperref[def:set_theory_definition/roster]{roster notation} we can define the \term[ru=неупорядоченная пара (\cite[181]{Герасимов2014Вычислимость})]{unordered pair} \( \set{ A, B } \).

  We do not require \( A \) and \( B \) to be distinct. In fact, if they are equal, we obtain a \hyperref[def:singleton_set]{singleton set}.
\end{definition}
\begin{comments}
  \item In \hyperref[def:zfc]{\logic{ZFC}}, the correctness of this definition relies on the \hyperref[def:zfc/pairing]{axiom of pairing} --- see \cref{thm:zfc_existence_theorems/unordered_pair}.

  \item We only need unordered pairs as a technical tool for defining binary unions and intersections in this sections and Kuratowski pairs in \cref{def:kuratowski_pair}. They are not by themselves an important concept.
\end{comments}

\begin{proposition}\label{thm:unordered_pair_extensionality}
  For \hyperref[def:unordered_pair]{unordered pairs} of sets (the universal closure of) the following is derivable:
  \begin{equation*}
    \set{ \syna, \synb } \syneq \set{ \sync, \synd } \syniff (\syna \syneq \sync \synwedge \synb \syneq \synd) \synvee (\syna \syneq \synd \synwedge \synb \syneq \sync)
  \end{equation*}
\end{proposition}
\begin{comments}
  \item For \hyperref[def:kuratowski_pair]{Kuratowski pairs}, we have the stronger statement \cref{thm:unordered_pair_extensionality}. For indexed families, we have \cref{thm:indexed_family_extensionality}.
\end{comments}
\begin{proof}
  After expanding the roster notation, we our goal becomes
  \begin{equation*}
    \qforall \synx (\synx \syneq \syna \synvee \synx \syneq \synb \syniff \synx \syneq \sync \synvee \synx \syneq \synd) \syniff (\syna \syneq \sync \synwedge \synb \syneq \synd) \synvee (\syna \syneq \synd \synwedge \synb \syneq \sync).
  \end{equation*}

  In one direction, we have the derivation
  \small
  \begin{equation*}
    \begin{prooftree}
      \hypo{ [\qforall \synx (\synx \syneq \syna \synvee \synx \syneq \synb \syniff \synx \syneq \sync \synvee \synx \syneq \synd)]^u }
      \infer1[\ref{inf:def:fol_natural_deduction/forall/elim}]{ \syna \syneq \syna \synvee \syna \syneq \synb \syniff \syna \syneq \sync \synvee \syna \syneq \synd }

      \infer0[\ref{inf:def:fol_natural_deduction/equality/intro}]{ \syna \syneq \syna }
      \infer1[\ref{inf:def:propositional_natural_deduction/or/intro_left}]{ \syna \syneq \syna \synvee \syna \syneq \synb }

      \infer2[\ref{inf:def:propositional_natural_deduction/iff/elim_right}]{ \syna \syneq \sync \synvee \syna \syneq \synd }

      \hypo{ \substack{ [\synanon]^u \\ [\syna \syneq \sync]^v } }
      \ellipsis {\( L \)} { \synanon }
      \infer1[\ref{inf:def:propositional_natural_deduction/or/intro_left}]{ \synanon }

      \hypo{ \substack{ [\synanon]^u \\ [\syna \syneq \synd]^w } }
      \ellipsis {} { \synanon }
      \infer1[\ref{inf:def:propositional_natural_deduction/or/intro_right}]{ \synanon }

      \infer[left label={\( v, w \)}]3[\ref{inf:def:propositional_natural_deduction/or/elim}]{ (\syna \syneq \sync \synwedge \synb \syneq \synd) \synvee (\syna \syneq \synd \synwedge \synb \syneq \sync) }
    \end{prooftree}
  \end{equation*}
  \normalsize
  where \( L \) is
  \small
  \begin{equation*}
    \begin{prooftree}
      \hypo{ [\syna \syneq \sync]^v }

      \hypo{ [\qforall \synx (\synx \syneq \syna \synvee \synx \syneq \synb \syniff \synx \syneq \sync \synvee \synx \syneq \synd)]^u }
      \ellipsis {} {\synb \syneq \sync \synvee \synb \syneq \synd}

      \hypo{ [\syna \syneq \sync]^v }
      \hypo{ [\synb \syneq \sync]^t }
      \infer1[\ref{inf:thm:fol_natural_deduction_equality/symm}]{ \sync \syneq \synb }
      \infer2[\ref{inf:def:fol_natural_deduction/equality/elim}]{ \syna \syneq \synb }
      \ellipsis {\( L' \)} { \synb \syneq \synd }

      \hypo{ [\synb \syneq \synd]^s }
      \infer[left label={\( t, s \)}]3[\ref{inf:def:propositional_natural_deduction/or/elim}]{ \synb \syneq \synd }

      \infer2[\ref{inf:def:propositional_natural_deduction/and/intro}]{ \syna \syneq \sync \synwedge \synb \syneq \synd }
    \end{prooftree}
  \end{equation*}
  \normalsize
  and \( L' \) is
  \begin{equation*}
    \begin{prooftree}
      \hypo{ [\qforall \synx (\synx \syneq \syna \synvee \synx \syneq \synb \syniff \synx \syneq \sync \synvee \synx \syneq \synd)]^u }
      \ellipsis {} {\synd \syneq \syna \synvee \synd \syneq \synb}

      \hypo{ [\synd \syneq \syna]^o }
      \hypo{ [\syna \syneq \synb]^r }
      \infer2[\ref{inf:def:fol_natural_deduction/equality/elim}]{ \synd \syneq \synb }

      \hypo{ [\synd \syneq \synb]^p }
      \infer[left label={\( o, p \)}]3[\ref{inf:def:propositional_natural_deduction/or/elim}]{ \synd \syneq \synb }
      \infer1[\ref{inf:thm:fol_natural_deduction_equality/symm}]{ \synb \syneq \synd }
    \end{prooftree}
  \end{equation*}
  and the other skipped subtrees are analogous.

  In the other direction, we have
  \small
  \begin{equation*}
    \begin{prooftree}
      \hypo{ [(\syna \syneq \sync \synwedge \synb \syneq \synd) \synvee (\syna \syneq \synd \synwedge \synb \syneq \sync)]^u }

      \hypo{ \substack{ [\syna \syneq \sync \synwedge \synb \syneq \synd]^v \\ [\synx \syneq \syna \synvee \synx \syneq \synb]^t } }
      \ellipsis {\( L \)} { \synanon }

      \hypo{ \substack{ [\syna \syneq \sync \synwedge \synb \syneq \synd]^v \\ [\synx \syneq \sync \synvee \synx \syneq \synd]^s } }
      \ellipsis {} { \synanon }

      \infer[left label={\( t, s \)}]2[\ref{inf:def:propositional_natural_deduction/iff/intro}]{ \synanon }

      \hypo{ [\syna \syneq \synd \synwedge \synb \syneq \sync]^w }
      \ellipsis {} { \synanon }

      \infer[left label={\( v, w \)}]3[\ref{inf:def:propositional_natural_deduction/or/elim}]{ \synanon }
      \infer1[\ref{inf:def:fol_natural_deduction/forall/intro}]{ \qforall \synx (\synx \syneq \syna \synvee \synx \syneq \synb \syniff \synx \syneq \sync \synvee \synx \syneq \synd) }
    \end{prooftree}
  \end{equation*}
  \normalsize
  where \( L \) is
  \small
  \begin{equation*}
    \begin{prooftree}
      \hypo{ [\synx \syneq \syna \synvee \synx \syneq \synb]^t }

      \hypo{ [\synx \syneq \syna]^r }
      \hypo{ [\syna \syneq \sync \synwedge \synb \syneq \synd]^v }
      \infer1[\ref{inf:def:propositional_natural_deduction/and/elim_left}]{ \syna \syneq \sync }
      \infer2[\ref{inf:def:fol_natural_deduction/equality/elim}]{ \synx \syneq \sync }
      \infer1[\ref{inf:def:propositional_natural_deduction/or/intro_left}]{ \synanon }

      \hypo{ [\synx \syneq \synb]^p }
      \hypo{ [\syna \syneq \sync \synwedge \synb \syneq \synd]^v }
      \infer1[\ref{inf:def:propositional_natural_deduction/and/elim_right}]{ \synb \syneq \synd }
      \infer2[\ref{inf:def:fol_natural_deduction/equality/elim}]{ \synx \syneq \synd }
      \infer1[\ref{inf:def:propositional_natural_deduction/or/intro_right}]{ \synanon }

      \infer[left label={\( r, p \)}]3[\ref{inf:def:propositional_natural_deduction/or/elim}]{ \synx \syneq \sync \synvee \synx \syneq \synd }
    \end{prooftree}
  \end{equation*}
  \normalsize
  and the other skipped subtrees are analogous.
\end{proof}

\paragraph{Algebra of sets}

\begin{definition}\label{def:set_union}\mcite[458]{Hinman2005Logic}
  We introduce two operations on sets, both called \term[ru=объединение (\cite[6]{ШеньВерещагин2020НачалаТеорииМножеств})]{union}.

  In accordance with \cref{def:set_theory_definition}, we introduce two \hyperref[def:fol_signature/function]{function symbol} using set-builder notation:
  \begin{thmenum}
    \thmitem{def:set_union/unary} First, we introduce the \hyperref[def:fol_signature/notation]{condensed} unary function symbol \( {\synbigcup} \):
    \begin{equation*}
      \synbigcup \syna \coloneqq \set{ \synx \given \underbrace{\qexists \syny (\syny \synin \syna \synwedge \synx \synin \syny)}_{\qexists {\syny \synin \syna} {\synx \synin \syny}} }.
    \end{equation*}

    Informally, \( \bigcap \mscrA \) contains all members of all members of \( \mscrA \) --- it \enquote{flattens} the set \( \mscrA \). Expressed more rigorously, the unary intersection is the multiplication operation of the power set monad --- see \cref{ex:def:monad/power_set}.

    \thmitem{def:set_union/binary} Second, we introduce the infix binary function symbol \( {\syncup} \):
    \begin{equation*}
      \syna \syncup \synb \coloneqq \set{ \synx \given \synx \synin \syna \synwedge \synx \synin \synb }.
    \end{equation*}

    Informally, the members of \( A \cup B \) belong to either \( A \) or \( B \).
  \end{thmenum}
\end{definition}
\begin{comments}
  \item In \hyperref[def:zfc]{\logic{ZFC}}, the correctness of the unary definition relies on the \hyperref[def:zfc/union]{axiom of unions} --- see \cref{thm:zfc_existence_theorems/arbitrary_union}.
\end{comments}

\begin{proposition}\label{thm:binary_set_union_via_pair}
  The \hyperref[def:set_union/binary]{binary union} \( \syna \syncup \synb \) is provably equal to the \hyperref[def:set_union/unary]{unary union} of the \hyperref[def:unordered_pair]{unordered pair} \( \set{ \syna, \synb } \), i.e. we can derive (the universal closure of)
  \begin{equation*}
    \syna \syncup \synb \syneq \synbigcup \set{ \syna, \synb }.
  \end{equation*}
\end{proposition}
\begin{comments}
  \item We will prove this by constructing \hyperref[def:fol_natural_deduction_proof_tree]{natural deduction proof trees}. The proposition is much easier to state and prove in a less formal metatheory:
  \begin{equation*}
    A \cup B = \set{ x \given x \in A \T{or} x \in B } = \set{ x \given \qexists* \syny \syny \in \set{ A, B } \T{and} x \in \syny } = \bigcup \set{ A, B }.
  \end{equation*}
\end{comments}
\begin{proof}
  We need to derive
  \begin{align*}
    \synx \synin (\syna \syncup \synb)        &\syniff \synx \synin \synbigcup \set{ \syna, \synb }.
  \intertext{We can substitute both sides with their definitions:}
    \synx \synin \syna \synvee \synx \synin \synb &\syniff \qexists \syny (\underbrace{\syny \synin \set{ \syna, \synb }}_{\syny \syneq \syna \synvee \syny \syneq \synb} \synwedge \synx \synin \syny).
  \end{align*}

  In one direction, we have
  \begin{equation*}
    \begin{prooftree}
      \hypo{ [\synx \synin \syna \synvee \synx \synin \synb]^u }

      \infer0[\ref{inf:def:fol_natural_deduction/equality/intro}]{ \syna \syneq a }
      \infer1[\ref{inf:def:propositional_natural_deduction/or/intro_left}]{ \syna \syneq \syna \synvee \syna \syneq \synb }

      \hypo{ [\synx \synin \syna]^v }
      \infer2[\ref{inf:def:propositional_natural_deduction/and/intro}]{ (\syna \syneq \syna \synvee \syna \syneq \synb) \synwedge \synx \synin \syna }
      \infer1[\ref{inf:def:fol_natural_deduction/exists/intro}]{ \qexists \syny ((\syny \syneq \syna \synvee \syny \syneq \synb) \synwedge \synx \synin \syny) }

      \hypo{ [\synx \synin \synb]^w }
      \ellipsis {} { \synanon }

      \infer[left label={\( v, w \)}]3[\ref{inf:def:propositional_natural_deduction/or/elim}]{ \qexists \syny ((\syny \syneq \syna \synvee \syny \syneq \synb) \synwedge \synx \synin \syny) }
    \end{prooftree}
  \end{equation*}

  In the other direction, we have
  \begin{equation*}
    \begin{prooftree}
      \hypo{ [\qexists \syny ((\syny \syneq \syna \synvee \syny \syneq \synb) \synwedge \synx \synin \syny)]^u }

      \hypo{ [(\syny \syneq \syna \synvee \syny \syneq \synb) \synwedge \synx \synin \syny]^v }
      \ellipsis {\( P \)} { \synx \synin \syna \synvee \synx \synin \synb }

      \infer[left label={\( v \)}]2[\ref{inf:def:fol_natural_deduction/exists/elim}]{ \synx \synin \syna \synvee \synx \synin \synb }
    \end{prooftree}
  \end{equation*}
  where \( P \) is
  \small
  \begin{equation*}
    \begin{prooftree}[separation=1em]
      \hypo{ [(\syny \syneq \syna \synvee \syny \syneq \synb) \synwedge \synx \synin \syny]^v }
      \infer1[\ref{inf:def:propositional_natural_deduction/and/elim_left}]{ \syny \syneq \syna \synvee \syny \syneq \synb }

      \hypo{ [(\syny \syneq \syna \synvee \syny \syneq \synb) \synwedge \synx \synin \syny]^v }
      \infer1[\ref{inf:def:propositional_natural_deduction/and/elim_right}]{ \synx \synin \syny }

      \hypo{ [\syny \syneq \syna]^t }
      \infer1[\ref{inf:thm:fol_natural_deduction_equality/symm}]{ \syna \syneq \syny }
      \infer2[\ref{inf:def:fol_natural_deduction/equality/elim}]{ \synx \synin \syna }
      \infer1[\ref{inf:def:propositional_natural_deduction/or/intro_left}]{ \synx \synin \syna \synvee \synx \synin \synb }

      \hypo{ [\syny \syneq \synb]^s }
      \ellipsis {} { \synanon }

      \infer[left label={\( t, s \)}]3[\ref{inf:def:propositional_natural_deduction/or/elim}]{ \synx \synin \syna \synvee \synx \synin \synb }
    \end{prooftree}
  \end{equation*}
  \normalsize
\end{proof}

\begin{proposition}\label{thm:unary_set_union_inequality}
  For the \hyperref[def:set_union/unary]{unary union}, we can derive (the universal closure of)
  \begin{equation*}
    \syna \synin \synb \synimplies \syna \synsubseteq \synbigcup \synb.
  \end{equation*}
\end{proposition}
\begin{proof}
  After expanding the definitions of \( {\synsubseteq} \) and \( {\synbigcup} \), the goal becomes
  \begin{equation}\label{eq:thm:unary_set_union_inequality/proof/goal}
    \syna \synin \synb \synimplies \qforall \synx (\synx \synin \syna \synimplies \qexists \syny (\syny \synin \synb \synwedge \synx \synin \syny)).
  \end{equation}

  It can be derived as follows:
  \begin{equation*}
    \begin{prooftree}
      \hypo{ [\syn\syna \synin \synb]^u }
      \hypo{ [\synx \synin \syna]^v }
      \infer2[\ref{inf:def:propositional_natural_deduction/and/intro}]{ \syna \synin \synb \synwedge \synx \synin \syna }
      \infer1[\ref{inf:def:fol_natural_deduction/exists/intro}]{ \qexists \syny (\syny \synin \synb \synwedge \synx \synin \syny) }
      \infer[left label=\( v \)]1[\ref{inf:def:propositional_natural_deduction/imp/intro}]{ \synanon }
      \infer1[\ref{inf:def:fol_natural_deduction/forall/intro}]{ \synanon }
      \infer[left label=\( u \)]1[\ref{inf:def:propositional_natural_deduction/imp/intro}]{ \eqref{eq:thm:unary_set_union_inequality/proof/goal} }
    \end{prooftree}
  \end{equation*}
\end{proof}

\begin{definition}\label{def:set_intersection}\mcite[458]{Hinman2005Logic}
  Dually to unions, we introduce two operations on sets, both called \term[ru=пересечение (\cite[6]{ШеньВерещагин2020НачалаТеорииМножеств})]{intersection}.

  In accordance with \cref{def:set_theory_definition}, we introduce two \hyperref[def:fol_signature/function]{function symbol} using set-builder notation:
  \begin{thmenum}
    \thmitem{def:set_intersection/unary} First, we introduce the \hyperref[def:fol_signature/notation]{condensed} unary function symbol \( {\synbigcap} \):
    \begin{equation*}
      \synbigcap a \coloneqq \set{ \synx \given \underbrace{\qforall \syny (\syny \synin \syna \synimplies \synx \synin \syny)}_{\qforall {\syny \synin \syna} \synx \synin \syny} }.
    \end{equation*}

    Informally, \( \bigcup \mscrA \) contains the common members of all members of \( \mscrA \). It is well-defined in naive set theory, however in \hyperref[def:zfc]{\logic{ZFC}} it can only be formally defined if \( \mscrA \) is nonempty since \( \bigcap \varnothing \) is the \hyperref[def:universal_set]{universal set}.

    \thmitem{def:set_intersection/binary} Second, we introduce the infix binary function symbol \( {\syncap} \):
    \begin{equation*}
      \syna \syncap \synb \coloneqq \set{ \synx \given \synx \synin \syna \synwedge \synx \synin \synb }.
    \end{equation*}

    Informally, the members of \( A \cap B \) belong to either \( A \) or \( B \). This definition is compatible with the restricted comprehension pattern described in \cref{def:set_theory_definition/restricted}, so it is always well-defined in \hyperref[def:zfc]{\logic{ZFC}} --- see \cref{thm:zfc_existence_theorems/binary_intersection}.
  \end{thmenum}
\end{definition}

\begin{proposition}\label{thm:binary_set_intersection_via_pair}
  The \hyperref[def:set_intersection/binary]{binary intersection} \( \syna \syncap \synb \) is provably equal to the \hyperref[def:set_intersection/unary]{unary intersection} of the \hyperref[def:unordered_pair]{unordered pair} \( \set{ \syna, \synb } \), i.e. we can derive (the universal closure of)
  \begin{equation*}
    \syna \syncap \synb \syneq \synbigcap \set{ \syna, \synb }.
  \end{equation*}
\end{proposition}
\begin{comments}
  \item We will prove this by constructing \hyperref[def:fol_natural_deduction_proof_tree]{natural deduction proof trees}. The proposition is much easier to state and prove in a less formal metatheory:
  \begin{equation*}
    A \cap B = \set{ x \given x \in A \T{and} x \in B } = \set{ x \given \qforall* \syny \syny \in \set{ A, B } \T{implies} x \in \syny } = \bigcap \set{ A, B }.
  \end{equation*}
\end{comments}
\begin{proof}
  We need to derive
  \begin{align*}
    \synx \synin (\syna \syncap \synb)        &\syniff \synx \synin \synbigcap \set{ \syna, \synb }.
  \intertext{We can substitute both sides with their definitions:}
    \synx \synin \syna \synwedge \synx \synin \synb &\syniff \qforall \syny (\underbrace{\syny \synin \set{ \syna, \synb }}_{\syny \syneq \syna \synvee \syny \syneq \synb} \synimplies \synx \synin \syny).
  \end{align*}

  In one direction, we have
  \begin{equation*}
    \begin{prooftree}
      \hypo{ [\syny \syneq \syna \synvee \syny \syneq \synb]^t }

      \hypo{ [\synx \synin \syna \synwedge \synx \synin \synb]^u }
      \infer1[\ref{inf:def:propositional_natural_deduction/and/elim_left}]{ \synx \synin \syna }

      \hypo{ [\syny \syneq \syna]^s }
      \infer1[\ref{inf:thm:fol_natural_deduction_equality/symm}]{ \syna \syneq \syny }

      \infer2[\ref{inf:def:fol_natural_deduction/equality/elim}]{ \synx \synin \syny }

      \hypo{ [\syny \syneq \synb]^r }
      \ellipsis {} { \synanon }

      \infer[left label={\( s, r \)}]3[\ref{inf:def:propositional_natural_deduction/or/elim}]{ \synx \synin \syny }
      \infer[left label=\( t \)]1[\ref{inf:def:propositional_natural_deduction/imp/intro}]{ (\syny \syneq \syna \synvee \syny \syneq \synb) \synimplies \synx \synin \syny }
      \infer1[\ref{inf:def:fol_natural_deduction/forall/intro}]{ \qforall \syny ((\syny \syneq \syna \synvee \syny \syneq \synb) \synimplies \synx \synin \syny) }
    \end{prooftree}
  \end{equation*}

  In the other direction, we have
  \begin{equation*}
    \begin{prooftree}
      \hypo{ [\qforall \syny ((\syny \syneq \syna \synvee \syny \syneq \synb) \synimplies \synx \synin \syny)]^u }
      \infer1[\ref{inf:def:fol_natural_deduction/forall/elim}]{ (\syna \syneq \syna \synvee \syna \syneq \synb) \synimplies \synx \synin \syna }

      \infer0[\ref{inf:def:fol_natural_deduction/equality/intro}]{ \syna \syneq a }
      \infer1[\ref{inf:def:propositional_natural_deduction/or/intro_left}]{ \syna \syneq \syna \synvee \syna \syneq \synb }

      \infer2[\ref{inf:def:propositional_natural_deduction/imp/elim}]{ \synx \synin \syna }

      \hypo{ [\synanon]^u }
      \ellipsis {} { \synx \synin \synb }

      \infer2[\ref{inf:def:propositional_natural_deduction/and/intro}]{ \synx \synin \syna \synwedge \synx \synin \synb }
    \end{prooftree}
  \end{equation*}
\end{proof}

\begin{proposition}\label{thm:unary_set_intersection_inequality}
  For the \hyperref[def:set_intersection/unary]{unary intersection}, we can derive (the universal closure of)
  \begin{equation*}
    \syna \synin \synb \synimplies \synbigcap \synb \subseteq \syna.
  \end{equation*}
\end{proposition}
\begin{comments}
  \item The instance where \( \synb \mapsto \varnothing \) seems problematic in \hyperref[def:zfc]{\logic{ZFC}} because \( \synbigcap \syn\varnothing \) is undefined, but the above can be regarded as a vacuous truth because \( \syna \synin \syn\varnothing \) is a contradiction in this case.
\end{comments}
\begin{proof}
  After expanding the definitions of \( {\synsubseteq} \) and \( {\synbigcap} \), the goal becomes
  \begin{equation}\label{eq:thm:unary_set_intersection_inequality/proof/goal}
    \syna \synin \synb \synimplies \qforall \synx (\qforall \syny (\syny \synin \synb \synimplies \synx \synin \syny) \synimplies \synx \synin \syna).
  \end{equation}

  It can be derived as follows:
  \begin{equation*}
    \begin{prooftree}
      \hypo{ [\syn\syna \synin \synb]^u }

      \hypo{ [\qforall \syny (\syny \synin \synb \synimplies \synx \synin \syny)]^v }
      \infer1[\ref{inf:def:fol_natural_deduction/forall/elim}]{ \syna \synin \synb \synimplies \synx \synin \syna }

      \infer2[\ref{inf:def:propositional_natural_deduction/imp/elim}]{ \synx \synin \syna }
      \infer[left label=\( v \)]1[\ref{inf:def:propositional_natural_deduction/imp/intro}]{ \synanon }
      \infer1[\ref{inf:def:fol_natural_deduction/forall/intro}]{ \synanon }
      \infer[left label=\( u \)]1[\ref{inf:def:propositional_natural_deduction/imp/intro}]{ \eqref{eq:thm:unary_set_intersection_inequality/proof/goal} }
    \end{prooftree}
  \end{equation*}
\end{proof}

\begin{proposition}\label{thm:lattice_of_sets}
  Binary \hyperref[def:set_union]{unions} and \hyperref[def:set_intersection]{intersections} of sets act as suprema and infima with respect to the \hyperref[def:inclusion_order]{inclusion order}.
\end{proposition}
\begin{comments}
  \item Thus, by \cref{thm:lattice_via_order_relation}, they satisfy the axioms of the \hyperref[def:lattice/theory]{theory of lattices}.
\end{comments}
\begin{proof}
  The following proof tree allows us to derive (the definitional expansion of) \( \syna \synvee \synb \synsubseteq \sync \) from \( \syna \synsubseteq \sync \) and \( \synb \synsubseteq \sync \):
  \footnotesize
  \begin{equation*}
    \begin{prooftree}[separation=1em]
      \hypo{ [\qforall \synx (\synx \synin \syna \synvee \synx \synin \synb)]^u }
      \infer1[\ref{inf:def:fol_natural_deduction/forall/elim}]{ \synx \synin \syna \synvee \synx \synin \synb }

      \hypo{ [\synx \synin \syna]^t }
      \hypo{ [\qforall \synx (\synx \synin \syna \synimplies \synx \synin \sync)]^v }
      \infer1[\ref{inf:def:fol_natural_deduction/forall/elim}]{ \synx \synin \syna \synvee \synx \synin \synb }
      \infer2[\ref{inf:def:propositional_natural_deduction/imp/elim}]{ \synx \synin \sync }

      \hypo{ [\synx \synin \synb]^s }
      \hypo{ [\qforall \synx (\synx \synin \synb \synimplies \synx \synin \sync)]^w }
      \infer1[\ref{inf:def:fol_natural_deduction/forall/elim}]{ \synx \synin \synb \synvee \synx \synin \sync }
      \infer2[\ref{inf:def:propositional_natural_deduction/imp/elim}]{ \synx \synin \sync }

      \infer[left label={\( t, s \)}]3[\ref{inf:def:propositional_natural_deduction/or/elim}]{ \synx \synin \sync }
      \infer[left label=\( u \)]1[\ref{inf:def:propositional_natural_deduction/imp/intro}]{ (\synx \synin \syna \synvee \synx \synin \synb) \synimplies \synx \synin \sync }
      \infer1[\ref{inf:def:fol_natural_deduction/forall/intro}]{ \qforall \synx ((\synx \synin \syna \synvee \synx \synin \synb) \synimplies \synx \synin \sync) }
    \end{prooftree}
  \end{equation*}
  \normalsize

  Furthermore, \( \syna \synvee \synb \) is an upper bound of \( a \) and \( \synb \) because we have \( \syna \synsubseteq \syna \synvee \synb \) by \ref{inf:def:propositional_natural_deduction/or/intro_left} and \( \synb \synsubseteq \syna \synvee \synb \) by \ref{inf:def:propositional_natural_deduction/or/intro_right}.

  Therefore, \( \syna \synvee \synb \) is indeed a supremum of \( a \) and \( \synb \).

  Similarly, from \( \sync \synsubseteq a \) and \( \sync \synsubseteq \synb \) we can derive \( \sync \synsubseteq \syna \syncap \synb \):
  \begin{equation*}
    \begin{prooftree}
      \hypo{ [\synx \synin \sync]^t }
      \hypo{ [\qforall \synx (\synx \synin \sync \synimplies \synx \synin \syna)]^v }
      \infer1[\ref{inf:def:fol_natural_deduction/forall/elim}]{ \synx \synin \sync \synimplies \synx \synin \syna }
      \infer2[\ref{inf:def:propositional_natural_deduction/imp/elim}]{ \synx \synin \syna }

      \hypo{ [\synx \synin \sync]^t }
      \hypo{ [\qforall \synx (\synx \synin \sync \synimplies \synx \synin \synb)]^w }
      \infer1[\ref{inf:def:fol_natural_deduction/forall/elim}]{ \synx \synin \sync \synimplies \synx \synin \synb }
      \infer2[\ref{inf:def:propositional_natural_deduction/imp/elim}]{ \synx \synin \synb }

      \infer2[\ref{inf:def:propositional_natural_deduction/and/intro}]{ \synx \synin \syna \synwedge \synx \synin \synb }
      \infer[left label=\( t \)]1[\ref{inf:def:propositional_natural_deduction/imp/intro}]{ \synx \synin \sync \synimplies \synx \synin \syna \synwedge \synx \synin \synb }
      \infer1[\ref{inf:def:fol_natural_deduction/forall/intro}]{ \qforall \synx (\synx \synin \sync \synimplies \synx \synin \syna \synwedge \synx \synin \synb) }
    \end{prooftree}
  \end{equation*}
  \normalsize
\end{proof}

\begin{definition}\label{def:lattice_of_sets}\mimprovised
  As long as we can prove their existence, binary \hyperref[def:set_union]{unions} and \hyperref[def:set_intersection]{intersections} of sets turn any \hyperref[def:set_theory_model]{model} of \hyperref[def:axiomatic_set_theory]{axiomatic set theory} into a \hyperref[def:lattice]{lattice}.

  \begin{figure}
    \hfill
    \includegraphics[page=1]{output/def__lattice_of_subsets}
    \hfill\hfill
    \caption{The \hyperref[def:hasse_diagram]{Hasse diagram} of \( \pow(\set{ A, B }) \) with respect to \hyperref[def:subset]{set inclusion}}
    \label{fig:def:lattice_of_subsets}
  \end{figure}

  This also holds more generally for any collection of sets that is closed under binary unions and intersections. We call such a collection a \term[en=lattice of sets (\cite[37]{DaveyPriestley2002LatticeTheory})]{lattice of sets}.

  Similarly, arbitrary unions and intersections act as joins and meets in a \hyperref[def:complete_lattice]{complete lattice}.
\end{definition}
\begin{comments}
  \item The \hyperref[def:universal_set]{universal set} and the \hyperref[def:empty_set]{empty set} act as the top and bottom in a given model of set theory. If we consider more restricted collections of sets, like we do in \cref{def:power_set_algebra}, the top and bottom are likely different.
\end{comments}
\begin{defproof}
  \Cref{thm:lattice_of_sets} implies that binary unions and intersections are suprema and infima, correspondingly, with respect to the inclusion order. Thus, by \cref{thm:lattice_via_order_relation}, they satisfy the axioms of the \hyperref[def:lattice/theory]{theory of lattices}.

  For arbitrary unions and intersections, we can give a simpler model-theoretic proof. Alternatively, we can devise a formal definition for complete lattices for set inclusion and utilize \cref{thm:unary_set_union_inequality} and \cref{thm:unary_set_intersection_inequality}.
\end{defproof}
