\chapter{Category theory}\label{ch:category_theory}

Category theory uses relationships between objects to study the objects themselves. This shifts the focus from an object's intrinsic properties based on set membership and function application.

We will define categories in \fullref{sec:categories} as \hyperref[def:directed_multigraph]{directed multigraphs} with additional structure. Such a definition allows us to work with categories while staying within a convenient \hyperref[con:metalogic]{metatheory} governed by \hyperref[def:axiom_of_universes]{\logic{ZFC+U}} (categories are actually the primary motivation for adding the \hyperref[def:axiom_of_universes]{axiom of universes} to \hyperref[def:zfc]{\logic{ZFC}}). Different approaches for defining categories are discussed in \cref{rem:category_size}.

The most essential topic beyond categories themselves are functors, which describe relationships between categories. These are discussed in \fullref{sec:functors}.

Beyond that, \fullref{sec:category_adjunctions} and \fullref{sec:categorical_limits} contain some topics important for us, and \fullref{sec:category_equivalences} fills some gaps.
