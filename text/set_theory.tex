\chapter{Set theory}\label{ch:set_theory}

We have dedicated \fullref{ch:mathematical_logic} to \hyperref[def:formal_language]{formal languages} with a notion of \hyperref[con:proposition]{formula} --- a concrete string of symbols encoding a (possibly \hyperref[con:hypothetical_judgment]{hypothetical}) \hyperref[con:judgment]{metalingual judgment}. Certain formulas can then be grouped into \hyperref[def:logical_theory]{theories}, allowing us to study \hyperref[con:logical_model]{models} --- external entities satisfying the formulas in the theory.

This approach reverses the historical development of mathematics. \hyperref[con:logical_system]{Logical systems} are developed so that they can encode theories of interest, which themselves arise by studying concrete models. For example, Peano has aided the development of \hyperref[con:predicate_logic]{predicate logic} with his arithmetical theory exhibited in \cite{Peano1889ArithmeticesPrincipia} --- what we now call \hyperref[def:peano_arithmetic]{Peano arithmetic}. The corresponding model --- the natural numbers, in their abstract form --- dates back to at least Ancient Greece\fnote{A historical account of ancient mathematics can be found in \cite{Kline1972MathematicalThoughtVol1}.}, with books VII to IX of Euclid's \enquote{Elements} dedicated to positive integers.

In a concrete model, there are two perspectives on logical formulas, which \textcite[125]{Enderton1977SetTheory} summarizes as follows\fnote{We discuss extensionality in \cref{con:extensionality}.}:
\begin{displayquote}
  If a couple of properties have the same extension (i.e., if they are true of exactly the same objects), are they in fact one and the same property? Is the property of being a prime number less than 10 the same
  as the property of being a solution to
  \begin{equation*}
    x^4 - 17x^3 + 101x^2 - 247x + 210 = 0?
  \end{equation*}

  If you answer \enquote{yes,} then one says that you are thinking of properties \textit{extensionally}, whereas if you answer \enquote{no,} then you are thinking of properties \textit{intensionally}. Both alternatives are legitimate, as long as the choice of
  alternatives is made clear.
\end{displayquote}

Enderton uses the above to describe sets as \enquote{extensions of properties}. This view of sets aligns with \cref{def:fol_definability}, where we introduce sets of \hyperref[con:predicate_logic/types]{individuals} definable by \hyperref[def:fol_formula]{first-order formulas}. It is also rather concrete because it provides a notion of \enquote{set} that depends on the concrete models and theories. For example, a set of real numbers has topological and order-theoretic properties, while a set of permutations has neither.

As a confirmation of the above remarks on historical development, set theory arose from abstracting away all aspects of sets except those expressible via membership.

We formulate the essence of set theory in \fullref{sec:naive_set_theory} and construct some basic notions in \fullref{sec:relations} and \fullref{sec:functions} so that we are able to state a proper axiomatization in \fullref{sec:zermelo_fraenkel_set_theory}.

We then study what grew out of Cantor's theory of infinite sets in \fullref{sec:ordinals}, \fullref{sec:cardinals} and \fullref{sec:transfinite_arithmetic}. This allows us to construct models of set theory in \fullref{sec:von_neumanns_cumulative_hierarchy} and \fullref{sec:grothendieck_universes}.

\begin{concept}\label{con:foundational_theory}
  In \cref{con:metalogic}, we have discussed how object theories are expressed within an ambient metatheory, and we have noted that some theories are rich enough to themselves serve as metatheories. We call such theories \term{foundational}.

  \begin{thmenum}
    \thmitem{con:foundational_theory/sets} The dominant approach is to use \hyperref[def:axiomatic_set_theory]{axiomatic set theory}.

    By default, this is \hyperref[def:zfc]{Zermelo-Fraenkel set theory} (\logic{ZFC}) or a variation like \hyperref[def:zfcu]{\logic{ZFC+U}} --- the one we use in this monograph --- or \hyperref[rem:small_category/reflection]{\logic{ZFC/S}}. There are also alternatives like \hyperref[def:nbg]{Von Neumann-G\"odel-Bernays set theory} (\logic{NBG}) that have a notion of \enquote{class} in addition to \enquote{set}. We compare these in \cref{rem:small_category} from the perspective of \hyperref[ch:category_theory]{category theory}.

    These are all theories of \hyperref[def:first_order_logic]{classical first-order logic}, but set theory can use other \hyperref[con:logical_system]{logical systems}. For example, as noted in \cref{def:zfc}, \hyperref[def:second_order_logic]{monadic second order logic} allows a more faithful encoding of \logic{ZFC}. We can also pursue \hyperref[con:intuitionistic_logic]{constructive (intuitionistic) logic}, with some notable downsides --- it would break equality, as explained in \cref{rem:intuitionistic_equality}, and it would conflict with the axiom of choice because of \fullref{thm:diaconescu_goodman_myhill_theorem}.

    Thus, a set-theoretic foundation requires both a logical system and a set theory. This is observed in \cite[17]{UnivalentFoundationsProgram2013HoTT}:
    \begin{displayquote}
      We note that a set-theoretic foundation has two \enquote{layers}: the deductive system of first-order logic, and, formulated inside this system, the axioms of a particular theory, such as ZFC. Thus, set theory is not only about sets, but rather about the interplay between sets (the objects of the second layer) and propositions (the objects of the first layer).
    \end{displayquote}

    \thmitem{con:foundational_theory/types} As manifested by the \hyperref[con:curry_howard_correspondence]{Curry-Howard correspondence}, a suitable \hyperref[def:abstract_type_system]{type system} like \hyperref[def:martin_lof_type_theory]{Martin-L\"of type theory} or \hyperref[def:homotopy_type_theory]{homotopy type theory} can act as a logical system. For this, only a part of the type system is sufficient --- for example, the types that are \hyperref[def:mere_proposition]{mere propositions}.

    Furthermore, the commonplace use of sets can often be translated by replacing set membership with \hyperref[def:type_habitation]{type habitance}, set union with \hyperref[def:dependent_sum]{sum types}, set intersection with \hyperref[def:dependent_product]{product types}, etc.

    The quote above continues as follows:
    \begin{displayquote}
      By contrast, type theory is its own deductive system: it need not be formulated inside any superstructure, such as first-order logic. Instead of the two basic notions of set theory, sets and propositions, type theory has one basic notion: \textit{types}.
    \end{displayquote}

    \thmitem{con:foundational_theory/categories} Yet another alternative is to take \hyperref[def:category]{categories} as primitive notions and develop theories inside specific categories, like how \hyperref[def:categorical_monoid]{internal monoids} can be defined in \hyperref[def:monoidal_category]{monoidal categories}.

    Reconstructing logic and set theory from categories alone is sketched in \cite{Awodey2009SetsTypesCategories}.
  \end{thmenum}
\end{concept}
